# 增量脚本（`server/sql/增量/`）

放**只给已有库打补丁**的一次性 SQL。完整约定见 `.claude/skills/system-details/reference/sql.md`。

三条硬规则：

1. **内容必须同时写回模块脚本**：增量做了什么，就把最终状态合并进对应的 `base.sql` / `blog.sql` / `ai.sql` / `meal.sql`，
   保证新库跑模块脚本就能一次到位；本目录的文件只服务于「已经建好、不想重跑模块脚本」的库。
2. **文件头必须注明**：内容已写入哪个模块脚本的哪一节，以及「本增量执行结束可删除」。
3. **执行完就删掉**：确认目标库执行成功后删除文件，不要长期堆在这里。

命名：`<主题>_<YYYYMMDD>.sql`（主题英文小写下划线），与模块脚本区分开。

## 文件头模板

```sql
-- ============================================================
-- <主题> 增量脚本
--
-- 已写入：<模块>.sql 的「<章节>」一节（新库跑模块脚本即可，不需要本文件）
-- 适用：只给已建好、不打算重跑 <模块>.sql 的库打补丁
-- 执行：mysql -u root -p howe-system < 增量/<文件>.sql
-- 本增量执行结束可删除。
-- ============================================================
```

> ⚠️ 模块脚本的建表是 `drop` + `create`，重跑会清空该模块的数据。已有库请走增量脚本。
